CONTACT / SUPPORT

Contact EXEcify.

Use the public project channels to ask a question, report a build problem or privately flag a security concern.

General questions and build problems

For usage questions, build failures and feature requests, open an issue in the public website repository. Include the language, a short description and the error message. Do not attach passwords, API keys or private source code.

Open a GitHub issue ↗

Security reports

For suspected vulnerabilities, use GitHub's private vulnerability reporting on the backend repository if available. Do not publish sensitive exploit details in a public issue.

Submit a private vulnerability report ↗

What to include

  • Which page or build step you were using.
  • The programming language and a brief description of the project structure.
  • The exact error text, with secrets and personal information removed.
  • Your browser and operating system, if relevant.

EXEcify is an independently maintained project, not a 24/7 support service. Do not send confidential code or credentials through public issues.
