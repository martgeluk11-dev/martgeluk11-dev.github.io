CONTACT / SUPPORT

Contact EXEcify.

Use the public project channels to ask a question, report a build problem or privately flag a security concern.

General questions and build problems

For questions, failed builds or feature requests, open a GitHub issue. Include the language, what you were trying to build and the error message. Remove passwords, API keys and personal information. Do not post private source code.

Open a GitHub issue ↗

Security reports

If you find a possible security flaw, use private vulnerability reporting on the backend repository if the option is available. Do not post exploit details in a public issue.

Submit a private vulnerability report ↗

What to include

  • The page or build step where the problem happened.
  • The programming language and a short description of the project structure.
  • The full error message, after removing secrets and personal information.
  • Your browser and operating system, if they are relevant to the issue.

EXEcify is maintained independently, so replies may take time. Do not send passwords, credentials or confidential source code through public issues.
