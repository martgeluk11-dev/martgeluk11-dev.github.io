DOWNLOAD TRANSPARENCY

Downloads & file verification.

Understand what EXEcify creates, how to verify a downloaded file and what Windows security warnings mean.

Do not upload confidential files. Only submit project files you are comfortable sharing with EXEcify and its service providers. Never include passwords, API keys, private keys, personal data or other sensitive information.

What you download

EXEcify returns the output created from your uploaded project. Depending on the format you choose, this is either a single EXE or a ZIP containing the app folder and its required files.

SHA-256 checksum

After the download, your browser calculates a SHA-256 hash for the file. The hash identifies that exact file. If the file changes, its hash changes too.

Use the VirusTotal link to search for an existing report for that hash. EXEcify does not send your file to VirusTotal. If you upload it there yourself, VirusTotal may share it with its security partners. Do not upload private or confidential files.

Windows warnings

EXEcify does not sign generated EXEs. Windows Defender or SmartScreen may warn you about new or unsigned files. Do not ignore a warning because the file came from EXEcify. Only run software you trust and have checked.

A matching hash confirms which file you have. It does not show whether the program is safe. A clean VirusTotal result cannot guarantee that either.

Builds are not security certifications

A completed build means EXEcify produced an output file. It does not mean the project passed a malware scan or security review. You are responsible for the code, dependencies and rights to distribute your project.
