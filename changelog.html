Changelog.

A public record of notable EXEcify website, build-service and security transparency updates.

23 November 2026

  • Added SHA-256 checksums for downloaded build files.
  • Added a VirusTotal hash-search link. Files are not automatically uploaded to VirusTotal.
  • Added guidance explaining checksum lookups and the privacy implications of uploading files to third-party scanning services.
  • Published a preliminary AI-assisted static security review of selected backend components.
  • Expanded public documentation for privacy, build processing and security limitations.

Earlier project updates

EXEcify has expanded from a Python-to-EXE converter to support additional project types, including JavaScript, TypeScript, C, C++, C#, Go and Rust. Support and build requirements can vary by language.

This changelog records notable published changes. It is not a complete commit history; the source repositories contain the detailed development history.
